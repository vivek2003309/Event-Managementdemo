Couture Scenography & Destination Nuptials Management Platform
A high-performance, bespoke web application engineered for The Wedding Dreams, an architectural wedding scenography and directorial management atelier based in Delhi Cantonment, New Delhi. This platform orchestrates the complete lifecycle of luxury destination nuptials—from prospective client consultations to active directorial planning and live client blueprints.

⚡ Tech Stack & Architecture
Built with a modular, decoupled architecture prioritizing sub-second client renders, cryptographic data isolation, and vector-level document reporting:
Frontend Core: React 18 with TypeScript
Build & Bundler: Vite (ESM native, HMR)
Styling Architecture: Tailwind CSS with custom design tokens (#C5A059 Atelier Gold, #171717 Obsidian Charcoal, #FBFBF9 Alabaster)
Database & Sync: Firebase Cloud Firestore with debounced real-time listeners and memory-leak guards
Authentication: Firebase Authentication with role-gated directorial routing (Admin Command Enclave & Client Sanctuary)
Data Visualization: Recharts (Custom SVG choreographies for 30-day milestone progress and velocity)
Document Engine: Custom jsPDF vector engine for client blueprints and director proposals (zero canvas/DOM dependencies)
Compliance & Privacy: India's DPDP Act (2023) compliant consent gates, sanitized client telemetries, and WCAG 2.1 AA accessible form inputs
📐 Platform Core Modules
1. Public Atelier Showcase
Editorial Scenography Gallery: Responsive masonry layout showcasing heritage fortresses, coastal sanctuaries, and private alpine estates.
Bespoke Service Offerings: Curated disciplines covering Destination Planning, Asian Wedding Architecture, Countryside Nuptials, and Milestone Soirées.
Consultation Gateways: DPDP Act compliant "Let's Talk" drawer with integrated WhatsApp Concierge routing.
2. Directorship Command Enclave (Admin Dashboard)
Triage Pipeline: Real-time inquiry handling, status progression (New, Contacted, Booked, Archived), and contact indexing.
Wedding Dossier Management: Milestone tracking, vendor assignment rosters, budget allocation calculators, and logistical timelines.
Vector Proposal Generation: Single-click PDF proposal compilation with live brand manifesto, scope breakdown, and verification timestamps.
3. Client Sanctuary Portal
Live Blueprint Synchronization: Real-time project roadmap mirroring director-side updates without client-side refreshes.
Financial Architecture: Transparent budget disbursement breakdowns and allocated commitments.
Confidential Blueprint PDF: Exportable vector blueprint containing schedules, logistics, and milestone progress (with client privacy redactions).
🛠️ Local Development & Deployment
Prerequisites
Node.js >= 18.x
npm >= 9.x
Installation
code
Bash
# Clone the private repository
git clone https://github.com/theweddingdreams/platform-core.git

# Navigate to project directory
cd platform-core

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
